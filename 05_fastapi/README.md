# 05. FastAPI

Python 함수를 HTTP API로 노출하는 웹 프레임워크입니다.

| 항목        | 내용                                                                                            |
| ----------- | ----------------------------------------------------------------------------------------------- |
| 과목        | AI 서비스 백엔드 프로그래밍 실무                                                                |
| 실습일      | Day 5–7 (9/8 화 ~ 9/10 목)                                                                      |
| 키워드      | 라우팅, 경로 파라미터, 요청 본문, CRUD, `HTTPException`, 쿼리 파라미터, `response_model`, PATCH |
| 필요 패키지 | `fastapi`, `uvicorn`, `streamlit`, `requests`                                                   |

함수 위에 데코레이터 한 줄을 붙이면 그 함수가 특정 URL의 처리기가 됩니다.

타입 힌트만으로 요청 값의 검증과 변환이 처리되고, API 문서까지 자동으로 생성됩니다.

## 사전 준비

```bash
pip install -r ../requirements.txt
```

day5·day6은 `fastapi`와 `uvicorn`만 있으면 되고, day7 프로젝트는 `streamlit`과 `requests`가 추가로 필요합니다.

가상환경 구성은 [저장소 루트의 가상환경 준비 항목](../README.md#가상환경-준비)을 참고합니다.

### 서버 실행

`python 파일.py`로는 실행되지 않습니다. ASGI 서버인 uvicorn이 앱을 불러와 구동합니다.

```bash
uvicorn day5_FastAPI01:app --reload
```

```text
uvicorn day5_FastAPI01:app --reload
        └─ 파일명 ─┘ └앱변수┘ └ 코드 수정 시 자동 재시작
```

| 주소                                 | 용도                                     |
| ------------------------------------ | ---------------------------------------- |
| `http://127.0.0.1:8000`              | API 기본 주소                            |
| `http://127.0.0.1:8000/docs`         | Swagger UI — 브라우저에서 직접 호출 가능 |
| `http://127.0.0.1:8000/redoc`        | ReDoc — 읽기 전용 문서                   |
| `http://127.0.0.1:8000/openapi.json` | OpenAPI 스키마 원문                      |

💡 `/docs`는 별도 설정 없이 자동 생성됩니다. 타입 힌트와 Pydantic 모델에서 스키마를 추출하기 때문입니다.
